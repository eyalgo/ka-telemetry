# ka-telemetry 0.2.0

The reports now say when a figure leaves values out. Everything in [0.1.1](0.1.1.md) still holds, except the one change under *Changed*.

## Added

- The per-agent report marks a figure that leaves values out. A figure followed by `(invalid: n)` is the sum of the values that were numbers: n values the row's requests carried for it were not a number, such as `true` or `"abc"`, and were left out. The `Total cost_usd` line counts the costs left out across all the rows.
- The rows under `subagent_completed counts Agent-tool agents only` carry the same mark beside `duration_ms` and `total_tool_uses`. Every record still counts in the row's `count=`.
- The block `--compare ATTR A B` adds carries the same mark for each side, so a side's total and its mean per run are taken from the values that were numbers. A request that left a value out still counts toward its run in `runs=`, and `--where` narrows these counts as it narrows the figures beside them.
- The totals check marks `log_cost_usd` and `metric_cost_usd` the same way: n counts the session's requests whose cost was not a number, or the points of Claude Code's cost metric whose value was not a number. Values left out can be why a session is marked `MISMATCH >1%`.
- With `--json`, each row, side or session that left a value out carries its counts in an `invalid_values` member, named by the keys of the figures they touch; the per-agent total's count sits in an `invalid_values` member after `total_cost_usd`.
- A value that is missing is not counted as invalid anywhere; only a value that is present and not a number is.
- The how-to says what the mark means in each report.
- `tools/measure_stream_cost.py`, run from a copy of this repository, generates stream data at three sizes, runs `agents` and `check` on each, and prints each run's peak memory and time. The how-to's section on reading reports now gives the figures one run of it measured, in place of its earlier unmeasured warning that a report on gigabytes takes a minute or more.
- [`docs/build_cost.md`](../docs/build_cost.md) gives what building ka-telemetry cost in Claude runs, tokens and money, and the README links it.

## Changed

- `ka-telemetry agents --prefix invalid_values` is refused, because `invalid_values` is now the name of a member the `--json` output adds to a row. Use `--where` to select requests by those attributes instead. `ka-telemetry turn-on --prefix invalid_values` is still accepted.
