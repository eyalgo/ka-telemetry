# ka-telemetry 0.1.1

A fix release. Everything in [0.1.0](0.1.0.md) still holds.

## Fixed

- The receiver starts listening at once. It no longer looks up the machine's own name when it binds its port; on a machine whose name lookups are slow, that lookup held its start for tens of seconds.

## Tests

- The tests pass on GitHub's Linux and macOS runners: the two release-check tests that try a pip install read no site-wide pip configuration, as the release check itself does, and two tests that depend on the machine allow for a slow resolver and for a Python that cannot be copied privately.
