# Contributing

Issues are welcome: a bug, a report whose figures look wrong, or a README step that did not work for
you. Say what you ran, what it printed and what you expected.

Pull requests are not taken for now. ka-telemetry is built with
[KensaiApp](https://github.com/eyalgo/kensaiapp), and its changes go through that pipeline, so an
outside pull request has no path in yet. An issue that describes the change is the way to ask for one.

Support is best effort, with no response-time promise; the README's Support section says what that
means.
